# Step 3: Verify no zombie processes remain
ps aux | grep defunct | grep -v grep || echo "No zombie processes"

# Output:
# No zombie processes

# Explanation: Confirms no zombie (defunct) processes were left behind.
# The SIGCHLD handler's waitpid() with WNOHANG ensures every terminated
# child is immediately reaped.

# Explanation of process creation, waiting, and signal handling:
#
# fork(): Creates child processes. Returns 0 to child, child PID to parent.
# Each child gets a copy of parent's memory and starts executing from the
# same point after fork().
#
# waitpid(): The SIGCHLD handler calls waitpid(-1, &status, WNOHANG) in a
# loop. -1 means "any child", WNOHANG makes it non-blocking. This reaps
# terminated children immediately, preventing them from becoming zombies.
#
# Signal handling: SIGALRM is triggered after TIMEOUT seconds via alarm().
# The handler sends SIGKILL to unresponsive children. SIGCHLD fires
# whenever a child terminates (naturally or via signal), triggering the
# reaping loop. This combination of alarm-based timeout and SIGCHLD-based
# reaping ensures no process is left unresponsive and no zombie is created.
